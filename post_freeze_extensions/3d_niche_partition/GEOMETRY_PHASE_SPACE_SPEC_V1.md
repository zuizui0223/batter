# Spatial-geometry phase-space specification v1

## Status

Descriptive synthesis fixed before the Pteropus external 3D-overlap result is opened.

This figure does not add a new hypothesis test. It visualizes the already-defined geometric components of individual specialization.

## Axes

For each source/panel:

H = self O_XY - other O_XY

- H > 0 means repeated sessions of the same individual overlap more strongly in horizontal space than sessions of different individuals.

V = self O_Z|XY - other O_Z|XY

- V > 0 means repeated sessions of the same individual have more similar centered vertical configuration within pairwise-shared horizontal cells.

S = other R_3D - self R_3D

- S > 0 means adding height removes a larger fraction of horizontal overlap between different individuals than between repeated sessions of the same individual.
- S is a descriptive segregation dimension and is not a separately calibrated primary test.

## Display

- x-axis: H
- y-axis: V
- point label: taxon/panel
- point size: absolute S, with sign written next to label
- vertical and horizontal zero lines define qualitative quadrants.
- structurally inferentially evaluable panels/sources use filled points.
- structurally non-evaluable sources may be shown as open points only if their descriptive H/V/S values exist; they are explicitly labelled "structural".
- no source is omitted because it falls in an inconvenient quadrant.

## Qualitative interpretation

Upper right:
NESTED 3D — horizontal fidelity plus repeatable vertical solution within shared space.

Lower right:
HORIZONTAL-DOMINANT — horizontal patch fidelity without clear vertical solution fidelity.

Upper left:
VERTICAL-DOMINANT — repeatable vertical solution without stronger horizontal self-overlap.

Near origin:
WEAK / EXCHANGEABLE geometry.

Large positive S:
stronger descriptive evidence that height adds between-individual niche separation beyond 2D overlap.

## Claim ceiling

The phase space visualizes realized geometry. It does not prove competition, intentional avoidance, resource partitioning, adaptation or causal ecological drivers.
