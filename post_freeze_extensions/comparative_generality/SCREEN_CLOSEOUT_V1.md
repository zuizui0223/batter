## Structural-scarcity conclusion

The principal limitation in the public source universe is not simply the number of available bat tracking datasets.

The required combination is rare:

> **native event-level vertical position × enough fixes within a session × repeated sessions within an individual × enough repeated individuals × cross-individual horizontal support.**

Several apparently large tracking datasets fail only after these dimensions are considered jointly.

This has two methodological consequences.

1. A literature count of “bat GPS datasets” substantially overstates the number of datasets capable of testing individual 3-D repeatability.
2. External generality cannot be established by repeatedly relaxing eligibility within the same programme, because doing so changes the estimand and source universe.
