## Core update

Version 10 established that spatial individuality is multidimensional.

Version 11 adds that those dimensions form different **configurations** among systems.

Observed configurations include:

- **high horizontal + high centered vertical** — *Pteropus poliocephalus*;
- **low horizontal + low centered vertical** — *Myotis vivesi*;
- **strong source-reported horizontal routine + centered vertical FAIL** — Hipposideros;
- **absolute vertical identity + centered-shape FAIL** — *Tadarida*;
- **centered vertical identity beyond coarse horizontal occupancy** — multiple original panels.

Thus:

> **the coupling among spatial-individuality axes is system-dependent.**

This is not yet a formal cross-source covariance model.

## External generality

A successful genuinely response-unopened external PASS now exists:

## Positive-system mechanism synthesis

Where centered vertical individuality is detectable, increasingly rich measured context can fail to explain it away.

This remains:

> **context-residual individuality where present**.

It is not generalized to negative systems.
