# Hipposideros structural gate v1

Outcome-blind prospective structural screen for the pre-existing external candidate
Dryad DOI `10.5061/dryad.j0zpc86r1`.

This stage is allowed to read only:
- file/column metadata;
- individual IDs;
- timestamps;
- longitude/latitude;
- presence or absence of the `height` field.

Numeric height magnitudes are prohibited.

The gate requires at least five individuals with at least two nights containing >=50
presence-qualified GPS fixes. A PASS still does not authorize vertical analysis until
individual-to-species mapping is resolved outcome-blind and a full vertical-validation
contract is frozen.
