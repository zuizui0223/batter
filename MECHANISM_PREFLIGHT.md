# Mechanism preflight v1

The repeatability result is already known. This preflight freezes a distinct second-stage
mechanistic question before inspecting annotated mechanism values.

## Question

Is repeatable individual place-by-height organization explained by repeatable differences in
response to the nocturnal energy landscape?

## Primary mechanism candidate

Individual-specific response to orographic uplift/topography:

`vertical response ~ energy-landscape predictor + (1 + predictor | individual)`

The mechanistic analysis will prefer terrain-relative height (AGL) over height above MSL if the
archived annotated table contains a documented terrain-relative field.

## Decision sequence

1. Open repository README and annotated-table column names only.
2. Map archived columns to: individual, time, position, terrain-relative height, wind/uplift,
   movement/flight state.
3. Freeze one primary response and one primary environmental predictor from documented semantics.
4. Only then open their numeric distributions and fit the reaction-norm model.
5. Secondary predictors cannot replace the primary if the primary is estimable.

## Claim boundary

This is post-primary mechanism analysis. It cannot alter the already obtained self-transfer result.
A mechanistic association does not establish an intrinsic personality, learning, optimality or
foraging unless those states are independently documented.
