## Design
From V22 deterministic 60±5s chains, four consecutive fixes form two history intervals and a target interval. Disjoint triplets of intervals (stride3, windows may share boundary). Require finite x/y/z/terrain and all three observed 55–65s intervals with chord speeds 2–50m/s and target abs vertical rate <=15 m/s; history quality gate depends only on horizontal coordinates/time (anchors already require finite altitude). Define prior route directness R = distance(t0,t2)/(distance(t0,t1)+distance(t1,t2)), 0–1; prior path speed = summed distance / summed dt; prior turning not calculated from target, no altitude in R. Target y = delta native absolute altitude / dt; q = delta terrain / dt on realized target horizontal path. Covariates start terrain, target log dt and chord speed, prior path speed, R. M0 baseline; M1 +q; M2 +q*R (also retain R main effect). Fixed ridge alpha10, training-only standardization, equal-animal training weights and equal-animal LOIO RMSE. No response-informed threshold/state classification. Predeclare contrast sign agnostic: a nonzero q*R coefficient only meaningful with held-out increment. Evaluate >=6 animals each >=50 windows, each >=10 windows in both R<=.85 and R>=.95 for a separate common-support sensitivity; main continuous model uses all eligible windows. Report R quantiles, signed q coverage, group counts, coefficient range and held-out delta, no p-value, no pooling across panels. Secondary target displacement association by low/high R descriptive; not proof of state-dependent behavior due to exposure variation. V27 primary original terrain only, no DEM or threshold tuning. If all fail or increment absent, close rather than search other cutoffs. Target path known, thus conditional height prediction rather than route-choice or foraging prediction. Note shared horizontal error and prior path autocorrelation, not a causal effect. No cave location exports.
