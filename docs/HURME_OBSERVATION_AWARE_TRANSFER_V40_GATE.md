# Hurme observation-aware behavioral transfer gate V40
Date 2026-11-25 JST. V39 source admission run 45426363648 in progress at drafting; no original source outcome or model outputs examined.
## Direct source method check
Hurme et al. 2019 Movement Ecology 7:21, https://doi.org/10.1186/s40462-019-0163-7, sections Methods: Analysis of on-board audio, Analysis of location data; Discussion. GPS every 15 s, audio 0.5 s every 5 s (10% duty cycle at 184 kHz). Buzzes identified by at least three consecutive calls with inter-pulse interval under 10 ms, automated screening then manual inspection; terminal and aborted buzzes included. Three nearest audio windows aggregated per GPS fix (before/during/after). Original authors report horizontal accuracy approximately 8 m and vertical 11 m (citing prior tag study, not source-specific calibration). In three additional 2017 bats with higher audio duty cycle, subsampling yielded bout detection 77 ± 16% (mean ± SD); this is bout-level, NOT per-fix sensitivity or detection probability of a single attack. They removed fixes within 250 m of island and subsequent tracks <100 locations. Straight outbound tracks contained buzzes not signaled by speed/turn changes. No assumption of perfect negative labels.
## V40 admission and analysis design; conditional on verified schema
Do not implement a fitted behavioral analysis until exact archived annotation and effort definitions are recovered. Required: explicit acoustically annotated detection field (not a movement-model state), authenticated trip/animal keys, timestamps, documented relationship between GPS fixes and audio windows. A scheduled recording is not proof of successful recording. Unknown observation effort never recoded as zero. If only GPS, or positive event list without observed effort, STOP event classifier; descriptive event localization only if link verified. If presence of recorded audio is verified but only binary detection, estimate probability of observed buzz given sampled audio, not true foraging probability. If verified number of valid audio windows (up to three per fix), include effort as fixed covariate, and complete three-window subset sensitivity. No multiplication/division by .77 or .10 to recover true events. Any bout-level comparison must maintain bout-level observation design.
Primary candidate incremental test: contextual prediction of observed buzz from prior path features rather than rescore same original segmentation. Training-only standardization; no using future response, GPS point is outcome location not available future habitat. Baseline time since trip onset and audio effort when varying; local movement model adds log prior speed and previous turn angle using contiguous timestamps, only past fixes and documented sampling cadence. Context model adds trailing 60 s speed/turn summaries (past contiguous records, same test support). Source annotated trip/roost exclusions only, no arbitrary island center; if missing use existing explicitly released analysis tracks as documented. Fixed ridge logistic models, held-out whole animals and held-out whole trips, never random point split. Report equal animal and trip average log loss, Brier loss, observed detection rates, positive-event support and prevalence baseline. Require at least 8 animals, 10 trips, 100 observed-positive fixes, 100 observed-negative fixes, and each evaluated block >=5 observed positives and negatives; exact eligibility frozen after schema audit but before numerical response fit. Do not infer unobserved negative labels. Primary positive criterion: contextual model improves both loss metrics in both group schemes, majority blocks, and mean loss gain remains positive under all single-block omissions. This tests transfer of detected-event predictability, not individual niche persistence, actual feeding or 3D habitat. No numerical altitude model given 11 m nominal accuracy and sea-surface capture geometry. If genuine same-event vertical field exists, separate coarse-scale audit only.
