## Fixed source grammar and QC

1. Re-fetch only original MD5/SHA256 ZIP and README. Parse only `3DTracks/coordinates_tracks/\*.csv` source fields, never PNG screenshots. Source may be **headerless numerical XYZ** generated by DLTdv5: admit only exactly 3 numeric data columns per source row if consistently formatted. If a valid *named* `x,y,z` header exists, explicitly identify it, but do not silently assume columns 2–4 for unlabelled 4-column files. **If not exactly 3 numeric XYZ per row, SOURCE_FORMAT_STOP** before outputting any spatial statistics. No CSV file is selected because it gives preferred height values; include every original source track separately with stable filename identity.
2. Treat source missing coordinates (blank, NaN, infinity, nonfinite) as **unlocalized rows** not zeros. Record valid 3D rows, missing rows, three-coordinate column schema, file counts and local bounding extents as **source coordinate units (unknown until author documents metre scale)**. Do **not** classify a local z as AGL, not GPS MSL, and do not infer a forest layer from positive/negative z.
3. Original `_uninterrupted_xyzpts.csv` is a **variant of the same original bat ID** and must never be counted as an independent flight. Report raw member count, distinct `(night,batID)` count and variant overlap; for future use, default to normal `_xyzpts.csv` and keep uninterrupted variant only for missingness QC, **not** both as two biological tracks. The expected published nights are 18 and 19 (Oct 2022), with 9+3 ≈12 original tracks per authors; if source filenames show fewer/more than source paper, report actual source names without inventing missing tracks.
4. Two `lamp_xyzpts.csv` files are original **local landmark point sets**; summarize each source shape and nonfinite value count, *not* fictitious georeferenced coordinates. This source does not automatically provide three noncollinear **known global tie points**, and one lamppost cannot determine arbitrary 3D rotation and translation to NRW LAS coordinates.
5. If zip has neither camera/flight metadata describing actual site GPS/UTM/EPSG and scale nor matching LAS acquisition and surveying control, mark **COLOCATION_NOT_IDENTIFIED**, even if the source supplies valid local 3D numeric tracks. No OpenNRW tile spatial intersection, vegetation nearest-distance, ALS tree density or 3D bat intensity can be honestly calculated.
6. Physical variance or flight kinematics may be reported later only after source coordinate **units and sample rate** are independently documented. A numerical tracking point is not an independent bat or call; do not fit Poisson point process on every coordinate as an independent event.
7. Do not use source trajectories to choose a favourable forest, species, clutter radius or height bin. The new source track QA is descriptive and cannot pass the independent-forest Gate C for original PR #103 with only two nights at one corridor.
