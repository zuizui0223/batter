## Source interpretation
Original paper §2.2–2.5, 3.1–3.2: 16 control/solar pairs at nine farms on nine nights, ~30m array detection volume, one farm sampled per night, ~3s trajectories. x,y,z are array/microphone-relative, not necessarily height above ground. Solar blind spots matched in control data by author filter; whether all public rows are postfilter uncertain. Classifier assigns feeding buzz probability per 0.5s acoustic file and joins to trajectory, not independently labeled captures at every reconstructed point. Classifier validation 141 manually checked recordings reported by authors, raw checks not supplied. Buzz score is proxy for acoustic prey-capture attempts, not success, actual prey density, true capture probability, or total habitat occupancy. Original study already compared speed/sinuosity and treatment effects. New question: does geometry of detected trajectories (array-relative z) improve buzz-score prediction beyond observation geometry and kinematic baseline when whole sampling nights/farms held out? Not re-estimating paper treatment effect or claiming new speed/buzz relationship.

Hold whole date/site connected components out; require at least 5 independent blocks, ≥100 trajectories overall and ≥10 test records per evaluated block. If only one site id reused across all dates, stop rather than split on unverified identity. Primary control sites identified only via unambiguous categorical code (control/C/temoin/control site), sensitivity pooled sites. All trajectories and 3+ observed positions; no forced source count. Outcome use published mean_buzz_proba if exactly constant within trajectory (tolerance 1e-8) and finite [0,1], otherwise stop those trajectories and report fraction; do not use mean_buzz_proba as predictor. Aggregate valid XYZ points, require ≥3 with finite coords, finite positive imprecision, nonnegative uncertainty widths (signed lower/upper displacement handled abs separately), and finite buzz outcome. Source distance r=sqrt(x²+y²+z²) as detection proxy. Mean/min speed from valid [0,20] m/s values; sinuosity median only valid [1,70], original speed/sinuosity cleaning respected where relevant. Report counts and missingness, same complete rows across models. 
Fixed trajectory-level models: D = site type, species/guild one-hot trained on training blocks, log1p(n positions), log1p(median radius), log1p(median imprecision), log1p(median vertical uncertainty width). K = D + log1p(mean speed), log1p(min speed), log1p(sinuosity); H = K + z median and z median squared (scaled on train), optional Hshape = H + z IQR (secondary only). All features preselected, no tuning. Fit fractional logistic loss with ridge=1 on standardized numeric and training one-hot, intercept unpenalized, label=published mean classifier score; use scipy optimizer with stable expit/logaddexp, no hard threshold. Equal test trajectory, equal block metrics soft-label log loss and squared error (not binomial independent event likelihood nor true calibration). Report mean losses, gains vs K, block wins, omission range of block gains, number of unseen taxon categories. Primary control-only K vs H; sensitivity all sites and stricter median vertical uncertainty <=2m, each same-row compare, min supports as above. No comparison of scores across different rows as treatment effect. Positive gate: H beats K in mean log loss and MSE in control-only and pooled, majority blocks positive log-loss gains and leave-one-block-out mean gain >0; uncertainty sensitivity report separately, no claim independent sites beyond sampled nights.
