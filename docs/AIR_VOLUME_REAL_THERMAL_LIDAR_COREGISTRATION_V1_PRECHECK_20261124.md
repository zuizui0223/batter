# Field-geometry co-registration gate v1: source-local thermal XYZ → projected LiDAR XYZ

**2026-11-24, before a real LiDAR tile is downloaded/paired or any spatial bat–clutter effect is estimated.** Genuine field thermal data from Heim et al. Zenodo `10.5281/zenodo.7797077` have now been authenticated and **197 valid local XYZ position records across 12 source coordinate target streams** verified [run #45207678824](https://github.com/zuizui0223/batter/actions/runs/45207678824), artifact 14833363665. These are **source numeric positions**, not confirmed 12 different individuals or georeferenced habitat-use points. The 3+6 column grammar and `pt2` were established from header-only sources before original numeric parsing. The archive has 2 lamp marker source CSVs, but **no published camera-to-NRW-ALS metric transform, surveyed world tie points, altitude datum or independently estimated bat trajectory q**.

This is a **source-free mathematical registration implementation**, NOT an inference that Münster open NRW LiDAR overlaps these bat tracks.

## Physical registration contract

- Source input consists of at least **three non-collinear** source-local 3D reference points and their correct one-to-one **independently surveyed matching world projected XYZ** points, plus at least **one extra independent, non-fitted world/local point pair** for validation. A single original lamppost landmark, regardless of its number of tracked positions/frames, is one physical object and does **not** satisfy this requirement. Fitting a camera/world rotation from the *bat track shape* is prohibited.
- The original source coordinate length scale **m per source-unit** must be documented from camera calibration or surveyed fiducial geometry, not estimated from the bat trajectories. Unknown or variable scale => registration STOP. Source z is not automatically AGL/MSL/orthometric height. Target world projected frame requires explicit horizontal EPSG projected metric CRS and vertical datum (e.g., source world surveyed orthometric height); do not combine EPSG:4326 degrees with metre LiDAR offsets.
- Fit a **proper rigid-body rotation** R (det +1, no reflection) and translation t by centered SVD/Kabsch on calibration points after the externally justified source→metre scale. Reject rank<2 source or target calibration point geometry (collinear/coincident) and ill-conditioned baseline with 2nd singular value ratio <.01 of 1st. Require source>=3 and validation>=1. Report RMS calibration residual, max validation residual, inferred rotation determinant, orthogonality residual and exactly which CRS/vertical datum was specified. No genetic/species data, canopy response or ecological outcome enters fit.
- **Predeclare** default admissible RMS calibration error <=0.5m and max independent validation error <=0.5m as a **prototype quality threshold only**, NOT an assurance that coarse ALS point cloud can resolve ~0.2m clutter. All thresholds can be made stricter in an independently designed experiment; do not loosen them post hoc after seeing residuals. A geometric **software PASS on synthetic controls** is never a field data PASS.
- A successful world transformation yields (E,N,projected Z) in a shared surveyed frame, **not yet airspace AGL**. AGL conversion requires a source DTM/ground surface with independently verified matching horizontal+vertical datum at each transformed xy; do not subtract a generic canopy height raster or assume camera local z is ground height.
- Apply transformed coordinates only to an *independently confirmed matching* exact LiDAR tile acquired near study period with known semantic vegetation returns and scanner visibility. A point cloud's absence of returns does not certify free-air voxels; 3D sensor q/error and track autocorrelation remain separate observational processes.
- Do not use the published publication map of Münster/Dortmund-Ems canal/forest Große Lodden to claim metre-accurate lamppost positions. Approximate geographic hints identify candidate search region, not surveyed fiducials.
- Return a fail-closed assessment if any calibration source condition is unmet. With **currently available original data** the expected scientific admission verdict is **REGISTRATION_STOP_UNVERIFIED_TIE_POINTS**, not a clutter preference or high-dimensional SDM result.
