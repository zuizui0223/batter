# European matched-pair multiscale profile-context test V1
2026-11-26 JST. New macro ecological analysis, frozen after earlier 1km result and independent-region support audit but before any 6/12km environmental associations or scores. This is a spatial-context scale test on identical 1km response comparisons, NOT a coarse-grain SDM fit or an independent biological replication. Keep V6, main, all original 20-taxon gates and earlier scores untouched. No more acoustic-stratum data work.

## Hypotheses
Hscale: the previously observed incremental information in a local relative-height profile is reduced when profile context is spatially averaged over 6/12km; local profile can still improve a broad-context model. Alternative: broader profile has greater incremental value, or there is no clear difference. Test all fixed scales regardless of sign. A scale effect could reflect averaging, contextual environment, observation bias or model support; it does not by itself identify bat movement range.
