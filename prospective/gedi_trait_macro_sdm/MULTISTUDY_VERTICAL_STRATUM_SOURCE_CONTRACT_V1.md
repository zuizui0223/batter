# Multistudy recorded vertical-stratum bridge — source gate V1, 2026-11-26 JST

New branch objective: a comparative synthesis of recorded height-stratum response across studies, distinct from the existing vertical-forest-profile paper V5/V6. No repeated single-study outcome search, no individual GPS archive work, no actual 3D occupancy claim. Freeze a bounded three-source acquisition set, not a comprehensive literature review. These are separate studies, not independent data rows from one experiment.

1. Erasmy et al. (2021/2022), https://doi.org/10.1002/ece3.8363, https://doi.org/10.5061/dryad.cjsxksn6m, official data page https://datadryad.org/dataset/doi:10.5061/dryad.cjsxksn6m. ## Admission and next computation
Source stage only: use the official API metadata and public file download, bounded max 40 MB per source, no retries on 401/403, no bypassing authorization. Save observed metadata, named-file content checksum if available, exact SHA256, column names, dimensions, missingness, categorical design levels and unique candidate survey units. No numeric response means, correlations, fits, or favorable species selection. Preserve source data only as allowed by license; otherwise use source pointers and checksum. Unknown field semantics, missing cells and unequal exposure must remain unknown, not manufactured absences. If public download is blocked, record status, don't repeat the same request.

Primary later estimand: relative *recorded detector-stratum activity* within each matched observation unit, harmonizing the lowest vs highest observed strata while retaining the original measurement type and height/exposure. Middle strata retained for separately defined within-study checks, not silently pooled. Require actual paired detector rows and counts/activity with explicit zero/missing semantics, species/sonotype definitions, survey effort documentation and independent site/study identifiers. Never combine minute-interval indices and passes as a single count likelihood; equal-weighted study-level predictive scores may be compared only under justified common outcome definitions. Same species labels need exact validated crosswalk; ambiguous complexes stay unresolved. A future cross-study holdout requires at least three independently eligible studies and a preregistered shared prediction target (species-level overlaps or independently harmonized physical traits), not merely three datasets. No calibrated height-resolved biological intensity without detection kernel/volume. No model until source audit and protocol freeze. Existing original 20-taxon SDM and manuscripts remain protected.
