# Observed return topology feasibility V1
2026-11-26 JST. Close same-archive Polesia ecological tuning. Goal: establish whether real aerial LiDAR return arrangement contains topology information not encoded by layer density. This is an environmental geometry test only, not an SDM or validation of bat passability. Existing air-volume branch and thermal stereo results unchanged.
Public USGS 3DEP EPT via https://registry.opendata.aws/usgs-lidar/; fixed projects NOAA InPort 67441 (NH_Coastal_1_2019), 67394 (NH_Coastal_2_2019), 73306 (WA_DNR_3DEP_Processing_1_2019). Use only their official public EPT URLs (no requester-pays bucket, credentials, guessed paths, or access-denial retry). Use EPT metadata boundsConforming, octree hierarchy and LAZ, all spatially intersecting nodes at every depth, including pagination through -1 nodes; validate exact decoded node counts. Document acquisition season/vertical reference differences; no claim of leaf-on or forest coverage. Reproject EPSG:3857 XY into local UTM metres, Z in documented metres. Fixed 3x3 interior positions (quartile, median, three-quarter of conforming XY extent), first three patches passing pre-specified support in lexicographic position order per project, independent of topology results. Each patch 64m x64m and 8m padding for ground, full vertical source extent. At most 1200 nodes and 250MB per project, 10 MB/node; on cap or failed transfer stop, not treat missing nodes as empty. Retain provenance of requested nodes, bytes hashes, bounds, classification. No co-location with actual bat surveys claimed.
Local ground model: nearest classified ground return (class 2), require nearest distance <=3m at every 1m horizontal center and <=3m for every obstacle return in inner patch. Exclude noise classes 7,18, withheld points; class 2 excluded from aboveground obstacle representation. Aboveground non-ground returns (incl unclassified) represented by binary occupied return voxels 1m cubic, 2–30m AGL (28 layers), excluding below-ground. Forest support: >=2 observed retained returns/m2, >=25% of horizontal 1m cells with at least one above-5m return; ground coverage as above; report every screened patch. This is a return-defined digital approximation, not vegetation volume, not inferred empty space; all unobserved voxels are unknown. Ignoring unobserved obstacles yields optimistic return-avoidance connectivity, not a rigorous upper bound for true physical passability after discretization/registration errors. 
For each patch construct graph of voxel centers not in occupied return voxels and not within 1 or 2 voxel center distances of occupied voxels (Euclidean distance transform; radius 0/1/2 m are numerical probes, not bat species wing lengths or maneuvering estimates). Use 6-neighbor graph, report available fraction, largest component / total graph domain, x/y face-to-face connected fraction, and fraction connected to bottom layer. Distances evaluated inside finite patch, no wrap. For 100 fixed-seed random within-layer permutations preserve exact occupied-voxel count at each AGL layer; compare observed connectivity to null including change across radii; report per patch null intervals, not independent species inference. Secondary deterministic 50% point thinning (before voxelization) and 2m voxel aggregation on matched 64m patches (keep 2–30m AGL, use 0/2m radii); compare metric shifts. Use synthetic checks with planar obstruction and layer-preserving randomized layout, monotonicity and count preservation. No biological response fit, no species-specific flight feasibility, no actual 3D occupancy claim, no substitution of missing returns as known free volume. If fewer than 2 projects or 3 total passing patches, report limited feasibility only. Preserve original results and main/frozen manuscripts.
