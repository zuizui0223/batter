Select ALL frozen forest-support cells in the documented national bounding rectangle 8.07..15.20 E, 54.56..57.75 N; actual national tile coverage and water masks delimit Denmark, not bbox alone. EPSG:6933 equal-area 1km. Joint 10m support excludes sea/inland water, building proportion >0, physically invalid/nodata. Aggregate means with projected area weighting; 0.70 joint support primary, 0.50/0.90 sensitivity; area-mean canopy height >5m. No missing as zero; valid canopy height 0 retained at the 10m level. Mean normalized height may be negative near terrain; retain valid negative values. Report Hmean/H95 (ratio of area means), ground/water return fraction, RH98/H95 scalar benchmark; not same waveform quantile or PAVD. Openness correlation secondary. No bat response fit. No direct south/north contrast from this dataset alone; 2014–15 vs 2020 temporal mismatch and differences in return weighting limit interpretation. If sample fails support, report rather than loosen.
