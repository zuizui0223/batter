## Estimand and comparison
Within the matched Danish measurement domain, conditional observed label-pair sorting, not occupancy, abundance, detection-adjusted choice, or causal selection. Compare only exact same source-year-spatial stratum, two distinct observed cells for two different taxa; never label an unrecorded species absent. Deduplicate source-year-cell-taxon; max 128 pairs per taxon-pair stratum sampled without replacement with fixed seed 20261126. 50km local blocks (not the original 200km admission rule); this is a smaller independent measured-structure diagnostic and not a relaxed continental test. All folds fixed by hash of spatial block ID; leave entire 50km blocks out. Equal total weights per scored block, equal group weight within block; groups are provider-year-block-species pair. Train-only environmental scaling. Same species-specific ridge slope family and fixed penalty 0.1 for every model; no tuning.

B: six CHELSA variables, five WorldCover class fractions (10,20,30,40,50), GVSM RH98, measured ALS H95. G: B + GVSM R50. L: B + measured ALS all-return mean height/H95. GL: B + both ratios. Both ratios are nonidentical structure proxies, not PAVD. Primary diagnostic G-B vs L-B, L-G and GL-G. Same rows and folds. Report raw scores, increments, # positive blocks, block quantiles. Descriptive conditional block bootstrap only, no independent pair-level p-values. Ground/water penetration NOT an extra predictor: no metric search. Secondary strict source+block holdout with same models if sufficient support; otherwise nonadmit. Require >=30 compared cells, >=10 comparison blocks, >=6 taxa, >=300 comparisons overall; within each fit >=300 train comparisons, >=6 train taxa, >=8 train blocks, >=10 test comparisons and >=2 test blocks, test taxa observed in training. At least 3 completed block folds, at least 8 scored blocks; report coverage and excluded folds. These are explicitly local diagnostic thresholds, never replace 20-species original SDM gate.

If L improves and G does not, measurement representation is a plausible limiting factor in this domain; if neither improves, does not identify biological null (metadata, temporal discrepancy, limited geographic support, differing proxies). If both improve, evidence is local predictive association, not explanation of continental transfer failure. If insufficient support, stop and report coverage. No further outcome-based tuning.
