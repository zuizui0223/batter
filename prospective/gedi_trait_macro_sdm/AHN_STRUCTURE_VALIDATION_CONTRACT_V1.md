Compare Pearson/Spearman, out-of-block prediction (50km blocks, 5 hash folds if >=10 blocks, same rows and folds) of ALS ratio with baseline GVSM RH98 + WorldCover tree fraction versus baseline+GVSM R50. Primary comparison RMSE gain (positive = baseline RMSE minus augmented RMSE), report south/north scored separately with same model and rows; if fewer than 30 cells or 4 spatial blocks per side, report descriptive/insufficient support.
