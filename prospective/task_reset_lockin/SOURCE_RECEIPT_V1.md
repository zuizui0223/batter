## Biological question

The completed bat programme now supports persistent personal-history information but not:
- continuing spatial exclusion;
- a common slow monotonic formation ramp;
- a detectable effect of broad enriched/impoverished early environment on history-carrier strength;
- simple body-mass matching;
- a universal fine-scale horizontal patch-fidelity explanation.

The strongest remaining mechanism class is rapid history-dependent lock-in.

The decisive discriminator is therefore a true task/environment change:

> **When obstacle geometry changes, does the old route solution break while a new stable solution rapidly forms, and does any individual-specific policy survive the route reset?**

## Distinguishing levels

The programme must keep three objects separate:

1. **route geometry** — the realized path through one obstacle arrangement;
2. **individual solution / policy** — repeatable individual-specific movement organization conditional on the arrangement;
3. **species policy** — shared species-level obstacle-avoidance rule.

The source paper already studies species-level policy.

The new prospective contribution is specifically the **individual × environment reconfiguration** problem.

## Primary mechanistic predictions

### History-dependent lock-in

Across a true arena change:
- similarity to the old realized route should fall;
- within the new arena, repeated flights should become more self-similar;
- any personal signature may re-emerge around a new geometry rather than preserve the old literal route.

### Immutable morphology-only routing

A stable performance constraint predicts stronger immediate transfer of individual-specific route organization across arena changes, with less need for within-arena re-stabilization.

### Pure reactive navigation

If flight is improvised anew on every trial:
- repeated within-arena self-similarity should be weak after accounting for obstacle geometry;
- individual identity should add little held-out prediction.
