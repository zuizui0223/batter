# Geometry-policy family ablation diagnostic v1

## Status

**POST-PRIMARY EXPLORATORY MECHANISM DIAGNOSTIC.**

Parent:
- `GEOMETRY_ONLY_POLICY_DIAGNOSTIC_CONTRACT_V1.md`
- `GEOMETRY_ONLY_POLICY_RESULT_V1.md`

The parent diagnostic established transferable individual identity using eight scale-free/angular route-geometry features after removing time, speed and absolute spatial scale.

This diagnostic asks whether that identity is carried by one narrow geometric statistic or is distributed across several aspects of route organization.

It cannot strengthen or rescue any confirmatory primary.

## Frozen feature families

Use exactly the eight already-frozen geometry-only features and their existing standardized values.

### Family G — global route organization
1. 3-D path efficiency
2. horizontal displacement ratio
3. absolute vertical displacement ratio
4. vertical range ratio

### Family H — horizontal maneuver geometry
5. median absolute horizontal turn angle
6. p90 absolute horizontal turn angle

### Family V — vertical maneuver geometry
7. median absolute vertical slope
8. p90 absolute vertical slope

No regrouping after output.

## Variants

### Family-only localization
- G only
- H only
- V only

### Leave-family-out robustness
- drop G: H + V
- drop H: G + V
- drop V: G + H

Use the exact parent cross-configuration identity estimator:
- equal environment centroids;
- leave target environment out;
- equal donor bats;
- equal target trajectories within bat;
- equal bats in programme statistic.

## Null

For every variant, use the exact parent environment-wise complete bat-label permutation.

9,999 permutations per variant.

## Main robustness diagnostic

Call geometry identity **robust to every broad family deletion** only if all three leave-family-out variants satisfy:
- K > 0;
- one-sided descriptive permutation p <= 0.05;
- >=4/5 evaluable bats positive.

This is deliberately stringent and exploratory.

## Interpretation

### Robust to all family deletions

Allowed:

> **Cross-configuration geometry identity is distributed across route organization rather than depending on one broad geometric component family.**

This is compatible with a coordinative solution architecture.

It is not direct evidence for environmental solution abundance.

### One deletion collapses identity

Allowed:

> geometry identity depends materially on the deleted component family.

### Family-only results

Use only to localize where identity information is strongest.
Do not select the strongest family as a new primary representation.

## Ceiling

Even distributed support does not establish:
- motor degeneracy as a causal mechanism;
- multiple feasible solutions from obstacle geometry;
- learning as the sole origin;
- independent neural modules.

The public obstacle geometry remains unavailable, so solution abundance itself remains unmeasured.
