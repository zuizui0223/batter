# Leave-one-environment carrier robustness contract v1

## Status

**POST-PRIMARY ROBUSTNESS DIAGNOSTIC. NOT CONFIRMATORY.**

Frozen after:
- movement-policy Primary B support;
- geometry-only policy support;
- pulse-policy support;
- pulse-component decomposition.

This diagnostic asks whether the portable individual signature is driven by one obstacle configuration.

## Scope

Species:
*Rhinolophus nippon*

Authoritative environments:
Env1–Env7.

Modalities:

1. **movement policy**
   - exact eight Primary B movement features;
   - exact environment standardization and leave-one-environment-out identity estimator.

2. **scale-free route geometry**
   - exact eight geometry-only features;
   - exact geometry-only preprocessing.

3. **echolocation timing**
   - exact six pulse features;
   - exact pulse preprocessing.

## Diagnostic operation

For each modality independently:

1. compute the full-data observed equal-bat identity statistic using all seven environments;
2. for each environment e in Env1–Env7:
   - remove every trajectory from e;
   - recompute all environment-specific preprocessing from the remaining data;
   - recompute the same cross-configuration identity statistic;
   - do not change features or support thresholds.

No new permutation p-values are calculated.

## Required reporting

For every modality report:

- full statistic;
- seven leave-one-environment-out statistics;
- minimum and maximum LOO statistic;
- minimum LOO / full-statistic ratio;
- number of LOO runs with positive statistic;
- minimum number/fraction of bats with positive individual identity advantage.

## Robustness interpretation

A modality is called **environment-robust** descriptively only if:

- all 7 LOO species statistics remain > 0;
- every LOO run has >=70% evaluable bats with positive individual means.

This is a robustness label, not a new significance test.

## Interpretation

If all three modalities are environment-robust:

> the portable individual sensorimotor signature is distributed across obstacle contexts rather than being generated by one exceptional configuration.

If one modality fails:
- identify the influential environment;
- do not delete it from the primary;
- retain the original primary result and report the sensitivity honestly.

## No rescue

Do not:
- select a subset of LOO environments;
- change feature sets;
- change preprocessing;
- convert LOO results into new confirmatory tests;
- omit an influential environment from the original primary.
