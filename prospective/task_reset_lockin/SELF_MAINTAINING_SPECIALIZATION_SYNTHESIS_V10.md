# 1. The original ecological puzzle

The frozen JAE result establishes that persistent individual vertical strategies can remain predictive even though strong additional 3-D spatial segregation is not generally supported.

In wild *Phyllostomus hastatus*:

- low-dimensional personal movement policy is repeatable;
- policy distance does not predict pairwise synchronous vertical separation;
- one year can show panel-level additional co-use separation without policy distance identifying which dyads separate.

Therefore:

[
oxed{
	ext{persistent individual strategy}

otRightarrow
	ext{persistent spatial partition}
}
]

This creates a mechanism problem:

> **If exclusive physical space is not the storage medium of specialization, where does individual information come from, how is it retained, and when is it expressed?**

The post-JAE programme now has separate evidence for each part of that question.

# 2. FORMATION — personal information is refined through movement history

## 2.1 The first-flight programme rejects one simple developmental model

A first-outdoor-flight fruit-bat archive follows juvenile movement through the first weeks of independent movement.

The frozen formation primary asked whether self-history advantage rises monotonically with accumulated independent experience.

Programme mean:
- positive relative to identity-exchangeability;
- p = **0.0102**.

But individual consistency failed:
- positive slopes = **8/14**;
- frozen requirement = **10/14**.

Verdict:

**FAIL_PRIMARY_FORMATION_RULE**

Thus development is not one common smooth canalization trajectory.

Do not describe individuality as gradually increasing at the same rate in most juveniles.

- calibrated excess = **+112.74**

## 2.3 Earliest observable personal history is not a stable long-term seed

A post-primary diagnostic used equal history depth to distinguish early predisposition from later refinement.

For every late target day 11–20:

- **early seed** = first 2 structurally valid independent movement days;
- **recent seed** = immediately preceding 2 structurally valid movement days.

Both histories therefore contain exactly two days.

Early-seed result:

- observed identity advantage E = **+15.19**
- null mean = **-0.14**
- p = **0.1655**
- positive juveniles = **8/14**

Verdict:

**UNSUPPORTED_EARLY_SEED_PERSISTENCE**

The earliest two valid personal movement days do not robustly predict late individual movement organization.

This weakens the simplest model in which the later personal spatial bias is already fully expressed at the beginning of independent movement.

# 4b. Portable individuality also survives removal of performance magnitude

A separate frozen post-primary diagnostic strips each trajectory of:
- time scale;
- speed magnitude;
- turn rate per unit time;
- absolute path length;
- absolute vertical range;
- absolute spatial offset.

Each route is start-centered and divided by its own total 3-D path length.

Eight dimensionless/angular route-geometry features are then used:
- path efficiency;
- horizontal displacement ratio;
- absolute vertical displacement ratio;
- vertical range ratio;
- median/p90 horizontal turn angle;
- median/p90 vertical slope.

All eight pass support across Env1–Env7.

Cross-configuration result:
- geometry-only K = **+0.38857**;
- **5/5 bats positive**;
- 9,999 permutations;
- null mean = **-0.0188**;
- p = **0.0153**.

Therefore the portable individual state is not carried only by raw performance magnitude such as speed or absolute movement scale.

It also contains a **scale-free route-organization component**.

This strengthens the interpretation of the adult state as a control/coordination bias.

It still does not by itself establish motor abundance or a feasible-solution manifold.

# 9. EXPRESSION — controlled sensory perturbation shifts behavior without erasing identity

Six bats experienced:
- no-masker baseline;
- 30-cm masker;

Within every condition, subtract the equal-bat population mean.

# 15. The revised life-history/control architecture

The mechanism is now best represented dynamically.

Let the portable individual coordinate be:

[
	heta_i(t).
]

Formation evidence says it need not be fully fixed at the earliest independent movement.

A schematic developmental model is:

[

	heta_i^{intrinsic}

where:
- (	heta_i^{intrinsic}) represents stable morphology, physiology and early developmental predisposition;
- (h_i(t)) represents accumulated personal movement/history-dependent sensorimotor organization.

Once formed/refined, current behavior is:

[
oxed{

alpha_{e,t}	heta_i(t),
lambda_{i,k(e)},
m_{i,e}

where:

- (	heta_i(t)): portable personal policy bias;

Not every term is independently identified in every dataset.

The value of the hierarchy is that different experiments constrain different levels.

# 17. The strongest current ecological story

The biological story is no longer simply:

> bats have persistent individual movement styles.

It is:

> **personal movement organization can be constructed through individual movement history, retained as a portable low-dimensional control bias, revealed to different degrees by current sensory/task context, and expressed in trajectories that can still overlap extensively with those of conspecifics.**

This resolves the original maintenance paradox.

Individuals do not need competitors to keep them physically separated in order to remain individually specialized.

The information can reside in the animal's evolving control/history state.

# 19. Remaining causal fork

The new ontogenetic result weakens a purely fixed predisposition account but does not eliminate intrinsic constraints.

The remaining origin problem is mixed:

[
	heta_i(t)
=
	heta_i^{biomechanics}
+
	heta_i^{development}
+
	heta_i^{long-term learning/history}.
]

A decisive future experiment should manipulate these components in the same individuals.

Highest-value design:

1. estimate portable policy coordinates;
2. apply a reversible biomechanical load;
3. remove the load;
4. independently train/reset a movement task;
5. remeasure the same policy coordinate;
6. repeat across contexts.

Predictions:
- biomechanical contribution changes reversibly with load;
- history/learning contribution changes with training;
- persistent identity component can be decomposed from both.

The next advance should alter a proposed causal carrier.

Another uncontrolled demonstration of repeatability is no longer sufficient.
