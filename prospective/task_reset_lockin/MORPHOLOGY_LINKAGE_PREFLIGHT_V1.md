# Same-individual morphology/physiology linkage preflight v1

## Status

**OUTCOME-BLIND CROSS-SOURCE IDENTITY AUDIT.**

This audit is frozen after:
- cross-configuration movement identity;
- geometry-only identity;
- pulse identity and route/movement-conditioned pulse identity.

It does **not** assume that companion studies used the same individual bats.

## Candidate companion source

Teshima et al. (2026), *evsBat: An automated toolkit for tracking and quantifying rapid movement of nocturnal animals using event cameras*.

Public data:
Figshare article **29150924**.

The paper reports laboratory use of *Rhinolophus nippon* and states that individuals were weighed before flight. This makes the source potentially useful for morphology/performance attribution **only if exact individual correspondence can be established independently**.

## Primary linkage question

Can the five *Rhinolophus nippon* individuals labelled A–E in the obstacle-flight archive be linked one-to-one to individuals in the evsBat archive using source-native identifiers or explicit cross-reference documentation?

## First-pass authorization

Read only public Figshare metadata:
- article title/id/DOI/version;
- file names;
- file ids;
- file sizes;
- hashes;
- file descriptions;
- directory/archive names where exposed.

Do not download file contents.

## Acceptable linkage evidence

A morphology attribution route may proceed only if at least one of the following is available:

1. the evsBat archive uses the same source-native individual labels A–E and source documentation states these are the same animals;
2. a table explicitly crosswalks evsBat IDs to the obstacle-flight A–E IDs;
3. the source paper/supplement explicitly says the same five *R. nippon* individuals were reused and gives reproducible identifiers.

Matching only:
- species;
- sample size of five;
- sex composition;
- laboratory;
- authorship;
- study period

is **not sufficient**.

## Candidate attributes if linkage passes

Only after a valid ID crosswalk is frozen may the programme inspect individual-level:
- body mass;
- wingbeat frequency;
- sex;
- other source-measured morphology or performance variables.

## Stop rule

If exact individual correspondence is unavailable:
- STOP same-individual morphology attribution;
- do not infer correspondence from matching sample size;
- do not correlate obstacle-flight A–E policy values with unordered evsBat morphology values.

A STOP is an identifiability result, not evidence against morphology.
