# Rhino geometry mechanism ceiling v1

## Status

**STOP SAME-DATA GEOMETRY-MECHANISM SEARCH.**

The opened Teshima *Rhinolophus nippon* archive has now been used to test the predeclared and bounded mechanism questions needed to locate the portable individual signal.

Further rotations, feature subsets, nonlinear decoders, environment selections, PCA dimensions or residual-feature searches from the same 45 trajectories are not authorized as evidence-generating analyses.

## What is established

### Portable coarse policy
Transparent I/M:
- 2-D identity K = **+0.55428**, p = **0.0001**;
- held-out coordinate R² = **0.4666**, p = **0.0002**;
- held-out pair-vector R² = **0.5797**, p = **0.0001**.

### Scale-free geometry identity
- K = **+0.38857**;
- 5/5 positive;
- p = **0.0153**.

Thus individuality is not only speed or absolute scale.

### Detailed geometry is less stable than policy
Geometry pair-vector:
- R² = **+0.1041**;
- median cosine = **0.597**;
- 75.8% positive;
- p = **0.0027**.

Geometry distance magnitude/ranking:
- Spearman ≈ **0.018–0.078** depending on matched diagnostic;
- unsupported.

### One universal I/M -> geometry decoder is insufficient
Cross-fitted other-environment decoder:
- residual geometry K = **+0.20160**;
- 5/5 positive;
- p = **0.0156**.

### A peer-estimated same-environment linear decoder is not identified
Two implementations:
- held-out geometry R² = **-1.419**;
- donor-only LOBO R² = **-0.365**.

Residual-identity disappearance after these poor predictors is not evidence for a successful shared decoder.

### Residual geometry is not one extra dominant axis
Training-only residual PCA:
- PC1 median variance = **57.0%**, identity p = **0.2284**;
- PC1+2 median variance = **74.2%**, identity p = **0.0608**;
- residual after PC1+2:
  - K = **+0.15833**
  - 5/5 positive
  - p = **0.0075**.

### Residual identity is maneuver-localized
After cross-fitted I/M removal:
- G global route residual: unsupported;
- H horizontal maneuver residual: **K=+0.19588, p=.0096**;
- V vertical maneuver residual: **K=+0.18380, p=.0031**.

## Why stop now

The remaining alternatives require information absent from the archive:
- known obstacle coordinates / affordance geometry;
- substantially more bats per environment;
- interventions on feasible solutions;
- independent biomechanical measurements;
- independent replication of fine maneuver residuals.

Continuing to rotate the same features would convert model localization into post-hoc pattern search.

## Authorized next evidence

Only new/independent information should move the mechanism:

1. designed obstacle geometry with known solution repertoire;
2. reversible biomechanical manipulation in the same individuals;
3. independent 3-D dataset with repeated individuals and explicit task geometry;
4. author-provided obstacle coordinates for the Teshima experiment.
