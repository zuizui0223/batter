# Strict source-date-only salvage plan: Wyoming Bighorn Mountain Moose

Recorded 20 October 2026 **after diagnosing timestamp syntax but before opening any rescued overlap outcomes**. Not an external preregistration. Source DOI [10.5441/001/1.714](https://doi.org/10.5441/001/1.714). The initial complete-source program stopped after 52,649 original GPS rows because all timestamp strings ended in the literal `S` (observed shape `YYYY-MM-DD HH:MM:dS`). A separate inspection of the original CSV and source reference found 52,648 GPS-visible, animal/tag-linked, valid-coordinate rows, spanning 21 animals in 2019 and 7 in 2020. All retained dates are valid `YYYY-MM-DD`; **seconds are not interpretable and must not be replaced with invented values**.

The recovery is limited to **2D pair-date geographic occupancy X**. Reject any source timestamp not matching the exact observed `S`-tail grammar, extract only year/month/ordinal date, retain original timestamp string solely as a duplicate key, and do not estimate step speed, R identity, co-presence T, or diurnal exposure. The source clock's UTC/GPS offset is not independently established. Require publisher MD5 for each complete GPS/reference ORIGINAL file. An unparseable date or position triggers STOP, never silent cohort restriction.

Apply the existing frozen cross-source geometric estimator **without changing** grid widths (1,2,5,10 km), four zero/half-cell origins, day equal-weighting, >=7 exact shared days per dyad-month, >=2 supported months in each season, and the same dyad-risk-set intersection across seasonal windows. Report Dec/Jan/Feb vs Jun/Jul/Aug and Jan/Feb vs Mar/Apr in each of 2019 and 2020, including no-support outcomes. All 00/10/01/11 transitions and the incidence/conditional-strength decomposition remain descriptive. No individual IDs, exact coordinates, day-level records or cell grids leave temporary analysis memory. The source has no independently verified local population labels; source-wide pair geographic overlap is not direct resource competition or social association.

The source-specific rescue is a new exploratory branch of computation and **does not retroactively change the prior STOP**. The prior stopped result and original source receipts remain archived. Review sampling-time ambiguity and source population membership before incorporating any recovered X into a biological comparison.
