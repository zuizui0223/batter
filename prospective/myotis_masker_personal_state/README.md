## Why this source matters

The broader batter programme already shows:
- personal movement information can persist across controlled task changes;
- personal history becomes more identity-informative;
- sensory perturbation can shift expression without erasing an individual movement bias.

The Myotis source supplies an independent species and independent perturbation architecture.

It is split into two evidence tiers.

## P1 — control experiment 1: sensorimotor-control triangulation

Five bats experience four current masking-source contexts:
- no noise;
- noise from target;
- noise above target;
- noise from side.

Source endpoint:
trial-level acoustic source level, with five source-selected loudest calls per successful trial.

Frozen identity analysis:
- equal trials -> equal source days -> bat × condition summary;
- condition centering removes the shared Lombard shift;
- leave-one-condition-out self-history advantage;
- exact null: fix no-noise labels and independently permute five bat identities in the other three conditions;
- exact assignment space = (5!)^3 = 1,728,000.

A positive result is **sensorimotor-control triangulation**, not a movement-policy replication.

## P2 — main experiment: landing-time behavior

Source endpoint:
- one row per trial;
- time_flight_s;
- five source masking conditions.

Frozen analysis:
- log flight time;
- equal-day bat × noise summary;
- noise-level centering;
- same leave-one-condition-out self-history architecture;
- exact full label-permutation null.

The source paper indicates common support may be only bats 1, 3 and 4.

Any positive result with B=3 is labelled:

CONTROLLED_SMALL_N_MOVEMENT_SUPPORT

and cannot be promoted to broad population generality.

## Evidence firewall

A positive result does not establish:
- origin of individuality;
- a universal bat policy coordinate;
- equivalence to Rhino FlightIntensity/ManeuveringExtent;
- the failed wild field carrier bridge;
- the causal effect of feasible-solution abundance.

It addresses only:

> does relative individual organization remain detectable while the current masking context is experimentally altered?
