# Public-data causal ceiling v1

## Status

**CURRENT PUBLIC-DATA-ONLY PROGRAMME BOUNDARY.**

This record answers:

> How far can the mechanism programme proceed without collecting new experimental data?

## Already supported from public data

### 1. Persistent individual organization exists

Across the post-JAE programme, repeated individuals retain predictive information across:
- obstacle configurations;
- held-out environments;
- independent external bat systems;
- developmental histories.

This establishes that the phenomenon is not one literal repeated route.

### 2. Personal history matters

Juvenile/history analyses show that later personal history becomes more informative about later individual movement than the earliest observed history alone.

This supports history-dependent refinement, while not identifying the full causal origin.

### 3. Current context changes expression

The same individual organization is expressed differently across tasks/environments.

Detailed route geometry is less portable than coarser individual organization.

### 4. Reversible sensory perturbation need not erase individuality

The public *Pipistrellus kuhlii* masker experiment already supports retention of a source-native movement bias across sensory perturbation.

A second independent public perturbation test is now opened prospectively from Diebold/Lawlor et al. 2024:
- reversible auditory-midbrain perturbation;
- four DREADDs bats in the public audio layer;
- structural gate PASS;
- exact four-identity primary frozen;
- numeric execution opened.

### 5. Independent navigation manipulation — SUPPORTED

Aharon et al. 2017 now provides a completed independent cross-condition identity test.

Frozen Figure-1 bilateral turning-location primary:
- 4 bats;
- 3 source-defined navigation conditions;
- K = **+3.695264**;
- **4/4 bats positive**;
- exact null = **576** mappings;
- exact p = **0.00347222**;
- all three condition-level mean advantages positive.

Thus:

> **individual navigation organization remains identifiable across experimentally altered current navigation conditions after common condition shifts are removed.**

The same-source identity search is now closed.

## What public data still cannot establish directly

The public archive universe now includes a randomized early-environment manipulation (Rachum et al. 2025), but that frozen primary did **not** confirm increased among-individual laboratory personality dispersion (D=+0.734699, p=0.167785).

Therefore public data do provide a causal history manipulation, but they do **not** support the simple formation mechanism:

[
\text{richer early environment}
\rightarrow
\text{more individual differentiation}.
]

The current public archive universe still does not independently manipulate:

[
\text{number of feasible movement solutions}
]

while holding identity and task constant and then test later specialization under equal current opportunity.

The Teshima archive lacks public obstacle geometry sufficient to define feasible-solution abundance independently of realized trajectories.

Therefore public data cannot currently establish the specific causal formation claim:

[
	ext{multiple feasible solutions}
ightarrow
	ext{formation of individual specialization}.
]

Do not infer solution abundance from:
- trajectory dispersion;
- number of route clusters;
- prediction error;
- file size;
- number of observed trajectories.

That would be circular.

## Public-data research target

The public-data-only paper should therefore center on:

> **Persistent individual organization can be retained across learning history and strong environmental/sensory perturbation while its realized behavioral expression remains context dependent.**

This is a mechanism-of-maintenance / storage-expression result.

It is not a direct experimental test of why individuality first forms.

## Stop rule

The frozen auditory-midbrain and Aharon navigation primaries are both disposed and supported.

Do not continue unbounded searches for new public datasets merely to accumulate more repeatability examples.

A new public source is worth opening only if it changes one of:
- biological identity while holding context;
- current context by experimental manipulation;
- personal history / learning;
- biomechanics / physiology;
- or independently specifies the feasible solution environment.

Another uncontrolled dataset showing that individuals differ is not sufficient.
