## Calculated exploratory results
Equal-layer probabilities p_h normalized separately. For categorical distance (0 within category, 1 between categories), Q(p)=1-sum(p^2); alpha=mean_h Q(p_h), gamma=Q(mean_h p_h), beta=gamma-alpha. JSD=H(mean_h p_h)-mean_h H(p_h). Both are nonnegative and not interchangeable.
Peters Table 2 normalized guild-score means, unlogged -> logged:
alpha 0.55765149 -> 0.51359939; gamma 0.58379773 -> 0.51897236; beta 0.02614624 -> 0.00537297; beta/gamma 0.04478648 -> 0.01035310; JSD 0.09689790 -> 0.03616104. Relative beta change -79.45%. This is a transformation of four rounded aggregate score vectors; no independent sampling unit or inferential interval, not a measurement of FD loss or causal effect. Species-specific capture-score definition and loss of one guild contribute. Not a pooled estimate for comparison to other studies.
Silva Table 1 preliminary transcription: species-identity distance ONLY, not trait distance. Equal-layer beta CF 0.02999244 -> fragment 0.04107954, JSD 0.34991718 -> 0.25399802. Common-36-label sensitivity beta 0.03130615 -> 0.04127112, JSD 0.32235210 -> 0.25327750. Opposite directions of beta vs JSD; source column margin discrepancy, aggregated habitats and no plot replicates make these non-admitted diagnostics. Do not select whichever diversity index agrees with the hypothesized loss. No biological effect claimed.
