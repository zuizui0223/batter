## Current decision boundary

No additional public-data analysis should be opened simply to add another context-persistence example.

A new analysis is justified only if it adds:
- randomized individual learning history;
- independently specified solution opportunity;
- sufficiently replicated reversible biomechanics;
- a prospectively testable allocation/reorganization mechanism not already analyzed in the source study.
