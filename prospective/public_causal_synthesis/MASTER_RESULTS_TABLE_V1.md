## Figure-use rules

1. Never place raw K, A, B, D, L, Q values from different endpoint families on one common quantitative axis.
2. Acute-perturbation synthesis may compare:
   - biological n;
   - positive-individual fraction;
   - exact/null rank;
   - support status.
3. Developmental panels may compare observed treatment contrasts only inside their own null distribution.
4. Post-primary diagnostics must be visually labeled as diagnostic/descriptive.
5. Wild H/V diagnostics must never share the same visual status as frozen confirmatory results.
