## 1. Authorship and affiliations

Fill:
- full author list in agreed order;

- corresponding author;

- telephone number if requested by submission system.

File to complete:
`COVER_PAGE_AND_ACKNOWLEDGEMENTS_V1.md`.

---

## 2. Funding

Behavioral Ecology requires a separate section titled **Funding**.

For every grant:
- funding agency;
- grant/project number;
- recipient author initials.

If there was no funding specifically supporting this reanalysis, state the accurate no-specific-funding wording agreed by the authors/institution.

Do not infer funding from source papers.

## 5. Acknowledgements

Add only:
- people who contributed but do not qualify for authorship;
- institutional/technical support if appropriate.

Obtain permission where the acknowledgement could identify a person's contribution.

Do not include acknowledgements in the anonymous review manuscript.

## 6. AI-use disclosure

Current draft disclosure says OpenAI ChatGPT was used for:
- literature triage;
- code review/drafting;
- analysis/provenance organization;
- figure-code drafting;
- substantial manuscript editing.

Before submission, human authors must verify:
- exact tool/model wording;
- actual date range;
- whether any additional AI systems were used;
- whether journal policy at submission date requires disclosure in Acknowledgements, cover letter, Methods, or all three.

All scientific/numerical claims must remain human-verified.

## 7. Anonymous review archive placement

Current clean package:
- build PASS;
- identifying repository-token scan PASS;
- package receipt in `ANONYMIZED_REVIEW_ARCHIVE_RECEIPT_V1.md`.

Required external action:
1. download the latest clean ZIP;
2. upload it to an anonymous review-capable repository/host or journal-provided anonymous file mechanism;
3. verify that the public/reviewer-facing page does not reveal author identity;
4. replace `[ANONYMIZED_REVIEW_ARCHIVE_URL]` in the anonymous manuscript if a link is used.

Do **not** use the identified GitHub Actions artifact URL in the manuscript.

For the final identified archive, use a permanent repository accepted by the journal rather than relying on GitHub as the sole archival location.

## 8. Supplementary Material PDF

Content complete:
- Table S1;
- Table S2;
- Figures S1–S3;
- Supplementary Methods S1–S2;
- publication-overlap disclosure.

Remaining action:
- convert to one PDF;
- visually inspect;
- keep under journal size limits;
- upload as the single Supplementary Material file.

Do not include executable code inside the PDF.

## 9. Publication-overlap status

Before submission, confirm the status of the separate JAE vertical-individuality manuscript:
- not submitted;
- submitted;
- under review;
- accepted;
- published/preprint.

Update the synthesis cover letter accordingly.

Mandatory boundary:
- overlapping public source datasets are disclosed;
- JAE primary vertical-shape effects are **not** counted as positive evidence in this synthesis;
- wild carrier result is used only as a failed downstream boundary.

---

## 10. Final scientific read

Have at least one human coauthor/PI read the complete anonymous manuscript specifically for:

- whether the biological question feels unified;
- whether heterogeneous source systems are sufficiently justified;
- whether maintenance evidence is oversold from small biological n;
- whether developmental nulls are phrased as "no simple effect on total individualization" rather than "no developmental effect";
- whether the failed wild bridge is clear rather than buried.

Do not reopen new datasets merely to answer stylistic reviewer anxiety.
