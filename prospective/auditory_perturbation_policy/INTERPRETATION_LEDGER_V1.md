## Exact-resolution warning

The confirmatory identity test contains exactly four biological DREADD bats.

Therefore:
- identity permutations = 24;
- minimum exact one-sided p = 1/24 = 0.0416667.

A conventional p <= 0.05 result is possible only at the extreme edge of the permutation distribution.

Thus a supported result should be interpreted as:

> the observed same-individual Saline-to-Ligand mapping is exceptionally identity-consistent among the 24 possible mappings in these four bats.

It must **not** be described as:
- high-powered population evidence;
- a precise effect-size estimate;
- proof of a universal individual acoustic trait.

## Outcome states

### State A — SUPPORTED

Requirements:
- K > 0;
- exact p <= 0.05.

Allowed programme update:

> A reversible central auditory perturbation can strongly alter common acoustic expression while preserving enough individual-specific multivariate organization for the true same-bat mapping to remain uniquely or near-uniquely optimal.

Mechanistic implication:

[
\text{central auditory perturbation}
\not\Rightarrow
\text{complete erasure of individual organization}.
]

This strengthens the storage-versus-expression interpretation.

It does **not** locate the storage substrate.

### State B — POSITIVE_BUT_UNRESOLVED

K > 0 but p > 0.05.

Allowed statement:

> the observed direction is compatible with retained individual organization, but four-bat exact resolution is insufficient to separate the true mapping from alternative identity mappings.

Do not call this supported.

Do not rescue with:
- one feature;
- three-bat subset;
- trajectory data;
- sham bats;
- trial-level mixed model treating calls/trials as independent biological replicates.

### State C — NO_POSITIVE_IDENTITY

K <= 0.

Allowed statement:

> under the frozen four-feature representation, Ligand acoustic organization is not closer to same-bat Saline organization than to other bats on average.

This is evidence against portability of **this frozen acoustic representation** across the perturbation.

It is not evidence that all individual state was erased.

## Feature robustness

Leave-one-feature-out results are diagnostic only.

If primary SUPPORTED but one feature deletion destroys K:
- label the identity signal feature-sensitive;
- do not redefine the primary.

If primary fails but one feature subset passes:
- no promotion;
- treat as exploratory only.

## Relation to existing Pipistrellus masker result

The earlier *Pipistrellus kuhlii* sensory-masker result and this *Eptesicus fuscus* auditory-midbrain perturbation differ in:
- species;
- sensory manipulation;
- behavioral endpoint;
- sample size.

If both support persistence, the correct synthesis is:

> individual organization can survive more than one kind of sensory/context perturbation across independent bat systems.

Do not call them identical carriers.

## Relation to Rhinolophus

A positive result would add an independent perturbational layer to the existing *Rhinolophus* cross-task portability evidence.

The bounded hierarchy would become:

[
\text{personal information}
\rightarrow
\text{portable / persistent individual organization}
\rightarrow
\text{context-dependent expression}.
]

It would still not establish:
- exact latent dimensionality;
- common neural coding across species;
- wild vertical-niche mediation;
- formation from solution abundance.
