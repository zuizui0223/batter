# 1. Why reparameterize the original Pólya model?

The original symmetric Pólya process used a per-route prior weight (a).

To compare environments with different numbers of feasible solutions (K), a cleaner abundance parameterization holds the **total initial exploration mass** fixed:

[
A>0.
]

Each of K initially equivalent solutions receives:

[
a_K=\frac{A}{K}.
]

Thus every environment begins with the same total prior/exploration strength A.

Only the number of available solutions changes.

---

# 2. History-dependent solution choice

For individual i, after n choices let (N_{ik}(n)) be use count of solution k.

The next choice is:

[
P_i(kmid n)
=
\frac{A/K+N_{ik}(n)}
{A+n}.
]

All individuals begin identically.

There is:
- no individual-specific parameter;
- no competition;
- no spatial exclusion;
- no assigned niche.

The limiting personal solution distribution is:

[
\\theta_i
\sim
\mathrm{Dirichlet}
left(
\frac{A}{K},\ldots,\frac{A}{K}
\right).
]

Population expectation remains uniform:

[
E[\\theta_{ik}]=\frac1K.
]

Thus persistent individual differences arise by stochastic symmetry breaking alone.

# 3. Exact abundance prediction

For two future choices from the same individual:

[
P_{\mathrm{self}}
=
Eleft[\sum_k\\theta_{ik}^2\right]
=
\frac{A/K+1}{A+1}
=
\frac{A+K}{K(A+1)}.
]

For two independent individuals:

[
P_{\mathrm{other}}
=
\frac1K.
]

Therefore the exact self-history identity advantage is:

[
\boxed{
\Delta_K
=
P_{\mathrm{self}}
-
P_{\mathrm{other}}
=
\frac{K-1}{K(A+1)}
}
]

or equivalently:

[
\Delta_K
=
\frac{1-1/K}{A+1}.
]

For fixed total exploration mass A:

[
\frac{partial \Delta_K}{partial K}
=
\frac{1}{K^2(A+1)}
>0.
]

Therefore:

> **Increasing the number of functionally adequate solutions increases the expected raw individual-identity advantage generated by history dependence.**

Boundary:

[
K=1
Rightarrow
\Delta_K=0.
]

With only one feasible solution, stochastic personal specialization cannot emerge in this model.

As (K\to\inftyoinfty):

[
\Delta_K
\to
\frac1{A+1}.
]

The effect saturates.

# 4. Exact between-individual policy divergence

For the symmetric Dirichlet:

[
\mathrm{Cov}(\theta)
=
\frac{1}{A+1}
left[
\mathrm{diag}(mu)-mumu^T
\right],
]

where:

[
mu=
left(
\frac1K,\ldots,\frac1K
\right).
]

For two independent individuals:

[
E|\\theta_i-\\theta_j|^2
=
2,\mathrm{tr}{\mathrm{Cov}(\theta)}.
]

Hence:

[
\boxed{
E|\\theta_i-\\theta_j|^2
=
\frac{2(K-1)}{K(A+1)}
}
]

which is exactly (2Delta_K).

Thus, under fixed total exploration mass:

> **more feasible solutions produce larger expected separation among personal policy distributions.**

Again:

[
K=1
Rightarrow
E|\\theta_i-\\theta_j|^2=0.
]

# 5. What A means

A controls how strongly early history can break symmetry.

Small A:
- weak common prior;
- early stochastic choices strongly influence later proportions;
- large persistent individual differences.

Large A:
- strong diffuse exploration prior;
- histories remain closer to population uniformity;
- weak personal differentiation.

Thus the model has two separable ingredients:

[
\boxed{
\text{solution abundance }K
}
]

and

[
\boxed{
\text{history sensitivity }1/(A+1).
}
]

Large K without history dependence does not create specialization.

Strong history dependence with K=1 cannot create specialization.

Both are required.

# 7. Context can compress expression without erasing stored individuality

Now separate latent personal policy from observable movement.

Suppose the latent state has K solutions:

[
\\theta_iinDelta^{K-1}.
]

Current context maps those K latent solutions into only M distinguishable expressed outcomes.

Let:

[
p_i=C\\theta_i,
]

where C is a many-to-one expression map.

For the clean symmetric case, partition the K latent solutions equally among M expressed classes.

Because Dirichlet distributions are closed under aggregation:

[
p_i
\sim
\mathrm{Dirichlet}
left(
\frac{A}{M},\ldots,\frac{A}{M}
\right).
]

Therefore observed between-individual divergence becomes:

[
\boxed{
E|p_i-p_j|^2
=
\frac{2(M-1)}{M(A+1)}
}
]

while the latent divergence remains:

[
\frac{2(K-1)}{K(A+1)}.
]

The expression-compression ratio is:

[
\boxed{
R_{\mathrm{expr}}
=
\frac{
E|p_i-p_j|^2
}{
E|\\theta_i-\\theta_j|^2
}
=
\frac{K(M-1)}
{M(K-1)}
}
]

for (1le Mle K).

When:

[
M<K,
]

observable individuality is compressed.

In the limiting case:

[
M=1,
]

all individuals show the same observed state:

[
p_i=p_j
]

even though their latent (\\theta_i) remain different.

This gives an exact distinction between:

[
\boxed{
\text{storage}

\neq
\text{expression}.
}
]
