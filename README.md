# batter

Ecological follow-up on individual vertical-space use in European free-tailed bats (*Tadarida teniotis*).

## Starting observation

The frozen ODSP analysis found substantial vertical thickness within the species-level model pool:

- H(Z|X,Y) = 1.39186 nats;
- 4.022 effective vertical states;

but the species-level location-conditioned map failed to transfer to both sealed bats.

This repository asks a new ecological question:

> Is that non-transferability generated by stable, individual-specific vertical strategies?

## Primary test

Eight tracked bats are each split chronologically into early and late halves inside the exact 18 five-kilometre cells and altitude bins frozen by the preceding ODSP endpoint.

Early data generate an individual vertical-state map for each bat. Each map is scored against every bat's later observations, producing an 8 x 8 source-to-target transfer matrix.

The primary statistic compares the eight identity-matched diagonal scores with all 8! permutations of source identity.

A positive result means that a bat's own earlier vertical map predicts its later flight altitude better than maps learned from other bats, after conditioning on horizontal cell and using a species-level cell-specific baseline.

This is a mechanism follow-up on an already-open public dataset, not an independent confirmation of the original ODSP endpoint.
