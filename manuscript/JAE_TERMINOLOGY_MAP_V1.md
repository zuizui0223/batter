# JAE-facing terminology map v1

## Purpose

Internal repository terms remain valid for audit/provenance files, but the reviewer-facing manuscript should use ordinary inferential prose.

| Internal repository term | Journal-facing wording |
|---|---|
| frozen design / frozen contract | pre-specified design / analysis plan; or “fixed before outcomes were examined” when chronology matters |
| frozen threshold / seed / gate | pre-specified threshold / seed / eligibility criterion |
| PASS | met the pre-specified inferential criterion; exceeded its permutation null when that is the exact result |
| FAIL | did not meet the pre-specified inferential criterion |
| structural STOP | structurally non-evaluable under the pre-specified support requirement |
| response unopened | vertical/numeric outcome had not yet been examined |
| outcome opened | outcome was examined |
| rescue prohibited | no post-result subset, threshold or endpoint change was permitted |
| programme closed | no further analyses were added to that analysis family |
| frozen permutation null | pre-specified whole-session permutation null |
| frozen external primary | pre-specified external primary analysis |
| replicated | use only for a source that met its prospective criterion; otherwise state the numerical result directly |
| 1/4 replication | prohibited compression; describe each source under its own design and state that the sources are not exchangeable prevalence trials |
| configurable individuality | do not use as explanatory framework; use ecological heterogeneity / ecological contingency |
| terrain explains X% | prohibited; attenuation ratio is descriptive and not a causal mediation fraction |

## Scope

This map governs reviewer-facing prose only. Machine-readable contracts, result ledgers and historical provenance files may retain PASS/FAIL/frozen terminology because those labels encode the original decision rules exactly.

No scientific claim, threshold or evidence classification is changed by this translation.
