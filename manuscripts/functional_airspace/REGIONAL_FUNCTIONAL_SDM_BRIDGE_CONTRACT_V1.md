# From movement niches to regional functional SDMs — prospective site-level bridge V1 (2026-11-25 JST)

## Scope and publication decision
Keep V2 and closed V52/V53 unchanged. Do not turn a small set of individual trajectories into a global 3D SDM. An independent spatial programme already exists at prospective/gedi-trait-macro-sdm-20261125, contract blob 6058fe4c184d87bc7ef4ec349611da81ac0fd77d. This paper-side bridge tests a different, complementary quantity: can relative detected feeding-related activity across surveyed sites be predicted beyond total observed bat activity? This is an independent regional detector-level extension, not a third GPS-trajectory replication, not height-calibrated occupancy, and not a validated global functional distribution. No changes to the parallel GEDI branch or main.

## Data gate before any new effect
Obtain only exact version-authorized files using documented official routes, bounded acquisition. Verify DOI, file IDs/name, size, published checksum when available and computed SHA256. Log only aggregate receipts and headers (not raw records, timestamps, site coordinates or local paths from INDIR/OUTDIR). Verify the pinned author preprocessing including all documented corrections, manual label rules, splitting and effort join; source-reconcile 19,438 total, 19,206 ground passes, 4,034 feeding ground passes, 547 social ground passes, 811 active ground nights and all 16 detector roles. Resolve any discrepancy before fitting; do not silently use regex shortcuts. Distinguish true observed positive, labelled nonfeeding pass, unknown label and missing detector effort. Restrict primary to ground detectors N/P pairs, active both sites same night, same guild SRE/LRE. Exclude unlabelled and unmatched passes explicitly, no zero-filling on inactive nights. Report original support and exclusions. MRE scarce; not a primary endpoint. Feeding is a subset of verified passes, NOT successful capture, abundance, or absolute use. The denominator is already detected and may differ by habitat, microphone or call type. Require >=6 locality pairs with >=5 informative paired nights each in BOTH guilds; informative means both sides have eligible passes and 0 < total feeding < total passes. No outcome-adaptive pooling, no relaxed gate.

## Conditional prediction model (frozen before source outcome)
For a paired site-night-guild stratum with nN natural passes, nP turbine-pad passes, and f detected feeding passes in total, let K be feeding passes at natural. The exact conditional probability on integer k from max(0,f-nP) to min(f,nN) is proportional to choose(nN,k)*choose(nP,f-k)*exp(beta*k). M0 beta=0 (hypergeometric distribution, pass-proportional allocation). M1 fit one common log odds ratio beta across the two guilds. M2 fit separate beta_SRE and beta_LRE. Conditional likelihood, fixed bound [-6,6], ridge 0.1*beta^2 per coefficient and equal-locality weighting: first average negative log likelihood over informative strata within locality, then average localities; for M2 optimize separable joint equal-locality loss plus penalties (each coefficient scaled by its guild share per locality). Use no test-locality response in fitting, no tuning. Hold out entire turbine locality in each fold; identical support all models. Compare mean stratum log probability (equal localities) M1−M0 and M2−M1, M2−M0. Primary M2−M0 positive, leave-one-locality summary omission positive, and improvement in >=5/7 (if 6 eligible, >=5/6); M2−M1 is incremental guild specificity, separately report no rescue. Report per-locality deltas and observed training coefficient ranges. No exact p-value asserted because repeated files/nights/individuals may violate conditional exchangeability. Directional guild contrast motivated by original published findings, not preregistered independent discovery. A site-level effect can be depletion or enrichment; entropy concentration is not assumed positive. This test conditions on observed later/pass totals, is not a prospective absolute event-count SDM, and does not establish true habitat function or causal effects. If source or model gate fails, report and stop, not reinterpret the failure as biology.

## Macro transfer
For species s at location x and height stratum z, define separately lambda_s(x,z) latent use, a_s(x,z) activity rate, and q_m(x,z) observation process for method m. Horizontal presence-background SDM with GEDI can learn relative marginal occurrence associated with vertical vegetation structure, not lambda_s(x,z) or a_s. Detector conditional marked fraction is P(mark|detected pass, site, guild), not a calibrated latent rate. Compare observed marked-fraction predictors across independent regions only when grain, taxon/guild, effort, label definition and support align; do not multiply arbitrary relative score by a conditional marked fraction to claim absolute function or diversity. First independent detector-level test, then additional regions with comparable outcomes; if three or more independent regions with compatible designs become available, freeze a study-level held-out transfer protocol, not a pooled site-level p-value. GPS V52/V53 support descriptive marked-use concentration, motivate a separate functional layer; never serve as macro validation. Actual 3D function requires paired stratum effort and independent detection calibration/identifiability, not just more 2D presences.
