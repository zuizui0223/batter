No visual/acoustic event tables downloaded.
Only conditionally analyze if FGDC gives unambiguous one-to-one roles for turbine identifier, date/night, acoustic bat event count, video bat event count, separate recorded acoustic effort and video effort in hours (or documented minutes, convert). Require counts of discrete bat detections, not duration, binary presence, estimated counts or all sound files. Use metadata and names only to determine mapping, require uniquely defined role; no selecting columns based on count sums/correlations. The code may stop if automatic semantic mapping is ambiguous; report actual dictionary then no outcomes computed. Explicit numeric or documented missing sentinel only (blank/NA/NaN/null); do not treat absence, device failure, missing count or effort as zero. Nonnegative integer counts, finite nonnegative effort, positive count with zero or missing effort flags provenance inconsistency and stop conditional analysis. Exact unique turbine-night key (documented date formats, no raw IDs/times), four turbine labels. Count rows, valid effort and overlap; require full modality-specific aggregate detection totals 244 and 384 if source defines counts of the report events, no matching by excluding rows. Report effort totals and discrepancy vs report without coercion (report rounds hours); if unambiguous definitions but totals differ, STOP and record, no fit. 
Primary: paired rows with both counts present and both positive effort, no equal-hours or fully overlapping interval assumption; rates counts per own recorded hour (separate support, not same volume/time window). Require >=3 turbines, >=20 paired nights per eligible turbine, nonconstant rates for both modalities. Require each of the four turbines represented in inventory; report omitted turbines/rows as aggregates. Eligible turbine criterion based on paired effort support only; if constant modality within eligible turbine, report rank undefined, stop primary rather than silently omit. Within each turbine, Spearman average ties and Pearson log1p rates, raw counts Pearson and Spearman as reference; equal-weight turbine mean, min/max and number positive (no turbine labels). Pooled descriptive Spearman separate, not independence. Top quartile high-activity sets within turbine: k=ceil(n/4); ties at cutoff share remaining membership mass equally (all higher=1, lower=0). Weighted overlap sum(min(a,b))/k, Jaccard sum(min)/sum(max). Under independent label permutation expected product overlap /k is k/n; use separate dot-product overlap sum(a*b)/k to compare to k/n (no p-value, min overlap not chance-adjusted). Report cutoff ties, positive counts, both-zero rows and fraction rate-defined. Same-date across turbines may share weather/activity; leave-one-turbine summaries descriptive, no inference or site holdout, no p-values. Primary fixed descriptive criterion mean within-turbine Spearman below .5 AND mean product overlap <.75 indicates incomplete ranking agreement, not evidence that true activity differs or a formal test. No tuning top fraction, effort thresholds, no test of event attribution. If data lack separate effort, no substitution of count-only analysis as successful external result.
