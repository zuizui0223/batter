## Question and target
Does within-individual prior recorded echolocation pulse cadence modify the conditional association between signed terrain change and subsequent vertical rate, beyond speed and prior height context? Not a test of causal sensing, actual emitted call rate, prey capture, or altitude-dependent sensory adaptation. Source Taub et al. 2023 (doi:10.1038/s42003-023-05563-x) has already studied IPI/height/speed associations; novelty candidate is out-of-individual prediction of subsequent terrain response, not replication of those associations.

## Fixed model and scoring
Response y=(native GPS height at t2 - height at t1)/dt_target. q=(Copernicus elevation at realized t2 - elevation at t1)/dt_target; observed future horizontal chord length/direction are conditioned upon, not forecast. V34 vertical baseline terms (log target dt, target horizontal chord speed, prior chord speed, origin terrain, actual heading/turn harmonics); prior native start height and prior vertical rate, prior signed terrain change rate, log(1+number of valid prior clips), and A = prior equal-clip log inverse IPI. To guard obvious context modification, include q, q*prior chord speed and q*prior native start height (native height not AGL; report shared-error sensitivity). B0 contains all those terms including A main effect, B1 adds only q*A. Interactions formed from raw features and standardized on training rows only. Do not count overlapping folds as independent replicates or run a significance test with windows as independent units.
