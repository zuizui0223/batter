# Empirical FD baseline V1 (prospective)
This does not constitute a result. Set before reading V3 outcome.
## Source
DarkCideS v4, DOI 10.6084/m9.figshare.16413405.v4; source paper DOI 10.1038/s41597-022-01234-4. Source paper describes adult mass in grams and three broad dietary groups (plant resources, animal resources, mixed); audit raw labels and missing sentinels before computing. Report actual file counts separately from publication totals. Cave coordinates are deliberately reduced in precision: no entrance-scale terrain inference or published cave IDs/coordinates.
Wing-trait candidate: Crane et al. DOI 10.1111/mam.12270, pooled species-level measured wing traits in Appendices S7–S9, Zenodo 10.5281/zenodo.4309198. Keep observed values separate from imputed. No confirmed download yet.
## Gate
Use V3 explicit cave key and independent corroboration only; require >=80% occurrence row verification, review lost rows, country/realm distribution, duplicate taxa, unresolved labels, mass units and diet codes. Do not call unresolved labels species. Presence incidence only; at least 3 complete taxa and >=80% coverage; sensitivity at 100%. Non-simultaneous reports are recorded assemblages not established coexistence. 
## Null model
Compute incidence Rao Q separately for log mass (range scaled on fixed eligible reference), dietary class (0/1), and their equal-weight combination. Primary estimand within-cave mean pairwise distance excluding diagonal (MPD); equivalently n/(n-1)*Rao Q, to remove deterministic diagonal richness factor. For each focal cave, derive trait-complete empirical species pool from other caves in same biogeographic realm, no focal record included. Fixed observed complete richness n; 999 draws without replacement, seeded. Sensitivity: same-country pool where pool >= max(15, 2*n) and >=10 other caves; frequency-weighted draws from regional record frequencies; use cave-level coverage and source sensitivity. Require same pool minimum for realm, exclude zero null variance from SES (retain observed minus expected). Report number of eligible caves and independent country/source units, distribution of observed-minus-null and SES by region. No global p-value treating caves as independent.
## Connectivity bridge
Only after independent data support: compare baseline (climate, regional pool, effort/source proxies, resource amount and habitat cover) + terrain geometry vs + independently calibrated trait-specific accessibility. Region-blocked validation, comparison on common complete rows. Use candidate guild pool independently of focal cave occurrence. Do not use focal community traits to build predictor. Test flight FD against resource FD on matched sets with comparable scaling/coverage. Mass and coarse diet are not validated substitutes for wing morphology. Resource FD is a comparator, not necessarily a negative control. No inference of competition or causal coexistence from incidence associations. No 3D empirical claim until terrain, altitude calibration, endpoints and held-out prediction pass.
